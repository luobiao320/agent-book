# KV Cache 友好的 Agent 上下文设计

> 来源章节：https://bojieli.github.io/ai-agent-book/book/chapter2/#kv-cache
> 本文为学习整理与重新讲解。

Agent 上下文可以按稳定性从前到后组织：

1. 稳定 system prompt；
2. 稳定或低频变化的工具/核心能力描述；
3. 历史消息与已完成轨迹；
4. 动态状态、最新工具结果；
5. 最新用户请求。

核心口诀是：**稳定内容靠前，动态内容靠后；尽量追加，减少改写前缀。**

但这不是绝对规则。权限、安全和语义优先级高于缓存优化。工程上应通过真实缓存命中率、TTFT、token 成本和任务成功率共同评估，而不是只看某一个性能指标。

## 一句话记忆

稳定前缀 + 动态后置 + 尽量追加。
