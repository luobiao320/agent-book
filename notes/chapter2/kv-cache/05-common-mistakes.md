# 破坏缓存复用的常见错误

> 来源章节：https://bojieli.github.io/ai-agent-book/book/chapter2/#kv-cache
> 本文为学习整理与重新讲解。

最典型的错误是把高频变化的数据放在 Prompt 最前面，例如当前时间、随机 ID、实时状态或每轮重写的动态摘要。只要公共前缀很早就发生变化，后面大量本来稳定的内容也难以作为同一前缀直接复用。

另一个问题是反复“改写历史”，而不是在末尾追加新消息。对缓存而言，append-only 通常比从中间修改更友好。

此外，不要为了追求缓存命中而牺牲正确性。安全规则、真实状态和任务所需信息必须优先保证语义正确。

## 一句话记忆

越早修改前缀，越容易丢掉后面大量缓存复用机会。
