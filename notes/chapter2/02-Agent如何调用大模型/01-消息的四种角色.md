# 消息的四种角色

原文：https://bojieli.github.io/ai-agent-book/book/chapter2/#消息的四种角色

## 核心结论

常见 Chat API 的 `messages` 由四类角色组成：`system`、`user`、`assistant`、`tool`。工具定义通常通过请求顶层的 `tools` 字段传入，不是第五种消息角色。

- `system`：开发者定义身份、行为规则和约束。
- `user`：终端用户输入。
- `assistant`：模型此前的回复，包括工具调用请求。
- `tool`：Harness 执行工具后的结果，通过 `tool_call_id` 关联调用。

## 工程理解

消息角色不是排版装饰，而是模型训练分布的一部分。把工具结果错误地伪装成普通用户文本，会让模型难以区分“用户指令”和“外部观察”。
