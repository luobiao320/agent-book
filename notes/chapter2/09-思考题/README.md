# 思考题

原文：https://bojieli.github.io/ai-agent-book/book/chapter2/#思考题

建议按下面主题自测，而不是直接背答案：

1. 如何同时控制上下文长度并保持 KV Cache 前缀稳定？
2. 超长 ReAct 循环中，历史 reasoning 应该保留、裁剪还是摘要？
3. 极端压缩如何避免不可逆信息损失？
4. 状态栏本身如果错误或被污染，如何降低风险？
5. 多人维护 System Prompt 时，如何通过工程实践抑制规则“熵增”？
6. 如果上下文学习更偏检索而非归纳，应怎样设计上下文供给？
7. Skill 的触发依赖模型元认知，如何避免漏触发？
8. 不同模型对动态 Skill 指令的遵从有什么差异？
9. 大量且频繁变化的工具集，如何设计上下文布局以最大化缓存命中？
