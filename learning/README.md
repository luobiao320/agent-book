## 推荐教学流程

每个知识块采用同一套流程：

1. **直觉**：先知道它解决什么问题。
2. **原理**：理解内部机制和关键约束。
3. **例子**：用具体 Agent 场景说明。
4. **工程类比**：尽量联系 Java、后端、缓存、消息队列、分布式系统等经验。
5. **常见误区**：明确哪些理解容易错。
6. **自测**：2～4 道题，先回答再看讲解。
7. **掌握确认**：能独立解释并解决场景题后，再在 `progress.md` 标记 ✅。

## 学习状态规则

- ⬜ **未学习**：还没有系统讲解。
- 🟨 **已接触**：已经讲过，但还没有通过自测确认掌握。
- ✅ **已掌握**：能够独立解释核心原理，并能处理工程场景题。

不要因为“看过/听过”就直接标记掌握。
