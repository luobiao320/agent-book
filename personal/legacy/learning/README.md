## 推荐教学流程

每个知识块采用同一套流程：

1. **直觉**：先知道它解决什么问题。
2. **原理**：理解内部机制和关键约束。
3. **例子**：用具体 Agent 场景说明。
4. **常见误区**：明确哪些理解容易错。

- ✅ **已学习**：已经讲过
