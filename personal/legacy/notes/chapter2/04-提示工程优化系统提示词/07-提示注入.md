# 提示注入：上下文安全的核心威胁

原文：https://bojieli.github.io/ai-agent-book/book/chapter2/#提示注入上下文安全的核心威胁

## 威胁模型

网页、邮件、文档、工具结果等外部内容可能包含伪装成指令的恶意文本。如果 Agent 拥有写文件、发邮件、调用业务 API 等工具，提示注入可能造成真实副作用。

## 上下文层防御

- 对外部内容显式标记来源。
- 严格使用 system/user/assistant/tool 等结构化角色。
- 对常见恶意模式做输入清洗，但不要把它当作唯一防线。

## 更可靠的防线

真正高风险的动作还需要 Harness 层的权限控制、沙盒、参数校验和人工确认。不能只靠再写一条 Prompt 来保证安全。
