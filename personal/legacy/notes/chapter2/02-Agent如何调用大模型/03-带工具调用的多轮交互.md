# 带工具调用的多轮交互：Agent 的核心循环

原文：https://bojieli.github.io/ai-agent-book/book/chapter2/#带工具调用的多轮交互agent-的核心循环

## 核心结论

典型工具调用循环是：

1. 用户提出任务。
2. 模型返回一个或多个 `tool_calls`。
3. Harness 真正执行工具。
4. 将工具结果以 `tool` 消息追加回历史。
5. 再次调用模型。
6. 模型如果不再请求工具，则生成最终答案。

模型负责“决定调用什么、传什么参数”，Harness 负责“真正执行动作”。

## 并行与串行

若多个工具调用互不依赖，可以并行执行；如果后一个工具的参数依赖前一个结果，就必须跨轮串行。
