原书首页：https://bojieli.github.io/ai-agent-book/

先掌握 1–5 章的 Agent 工程主线，再学习 6 章评估；7–8 章解决“如何让模型/Agent 从反馈中变好”；9–10 章扩展到多模态实时环境和多 Agent 系统。
